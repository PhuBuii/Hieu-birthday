# Cần bổ sung

Tự tạo bằng `npm run check` từ `content.json`. Còn **0 chỗ trống bắt buộc**, 0 mục tùy chọn.

Trong thiệp, các chỗ này hiện bằng **khung nét đứt vàng** kèm nhãn "Chỗ trống" (khi `"draftMode": true`). Nút "Bản nháp · N chỗ trống" ở góc màn hình mở cùng danh sách này.

## Ngoài content.json

- [ ] Bảng hình AI trong `assets/sheets/` (prompt ở `docs/PROMPT-HINH.md`)
- [ ] Khi có địa chỉ thật: sửa `og:url`, `og:image` (địa chỉ tuyệt đối) trong `index.html`
- [ ] Thử trên điện thoại thật: Safari iPhone, trình duyệt trong Messenger và Zalo
- [ ] Khi đã đủ: đặt `"draftMode": false` rồi `npm run build`
